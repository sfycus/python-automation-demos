# IntakeBot — приём заявок в Telegram

Демонстрационный бот задаёт клиенту три вопроса, сохраняет структурированную заявку в SQLite и уведомляет оператора. Оператор может посмотреть последние заявки (`/list`) и закрыть заявку (`/done 1`). Бизнес-логика отделена от сетевого адаптера, поэтому сценарий можно проверить локально без токена.

## Локальная демонстрация и тесты

```bash
python3 demo.py
python3 demo_server.py
python3 -m unittest -v test_core.py
```

Веб-симулятор будет доступен по адресу http://127.0.0.1:8766. Кнопка «Пройти пример» вызывает тот же `IntakeService`, что использует адаптер Telegram.

## Запуск в Telegram

Создайте собственного бота через официального BotFather и узнайте свой числовой chat ID. Установите переменные окружения, не записывайте токен в код:

```bash
export BOT_TOKEN='ваш_токен'
export OPERATOR_CHAT_ID='ваш_chat_id'
python3 telegram_bot.py
```

Команды клиента: `/new`, `/start`. Команды оператора: `/list`, `/done НОМЕР`.

Демо использует локальный SQLite и long polling. Для рабочего внедрения потребуются согласованные сроки хранения данных, резервное копирование, мониторинг и правила обработки персональных данных.
