# QuoteFlow — демонстрационный расчёт КП

Небольшой локальный сервис: Python API проверяет состав оборудования и считает сумму; JavaScript интерфейс показывает результат и сохраняет HTML-черновик КП.

## Запуск

```bash
python3 server.py
```

Откройте http://127.0.0.1:8765. Зависимостей нет.

## Проверка

```bash
python3 -m unittest -v test_quote.py
```

Попробуйте заменить `ATS-12` на `ATS-20` при генераторе `GEN-12`: сервер вернёт ошибку несовместимости. Данные каталога демонстрационные. Это прототип для портфолио, не готовый расчёт реальной электростанции.

## API

- `GET /api/catalog` — демонстрационный каталог.
- `POST /api/quote` — расчёт по JSON вида:

```json
{"customer":"ООО Тест","items":[{"sku":"GEN-12","quantity":1},{"sku":"ATS-12","quantity":1}],"discount_percent":5}
```

В реальном проекте каталог, цены, правила совместимости, роли и интеграцию с 1С согласуют с заказчиком отдельно.
